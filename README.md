# BNK48 Omikuji - 28 ใบเซียมซีแห่งพลังใจ

เว็บแอปพลิเคชันสำหรับเสี่ยงทายและอ่านคำทำนายเซียมซีจาก 28 บทเพลงความหมายดีของ BNK48

## วิธี Deploy ขึ้น Vercel ใน 1 นาที

### วิธีที่ 1: Deploy ผ่าน Vercel CLI (ง่ายและเร็วที่สุด)
1. ติดตั้ง Vercel CLI (หากยังไม่มี):
   ```bash
   npm install -g vercel
   ```
2. สั่งรันคำสั่งในโฟลเดอร์นี้:
   ```bash
   vercel
   ```
3. กด Enter ตามขั้นตอน จะได้ URL เว็บไซต์พร้อมใช้งานทันที!

### วิธีที่ 2: Deploy ผ่าน GitHub + Vercel Dashboard
1. สร้าง New Repository บน GitHub แล้ว Push โฟลเดอร์นี้ขึ้นไป
2. ไปที่ [vercel.com](https://vercel.com/) -> กด **Add New...** -> **Project**
3. เลือก Repository ที่เพิ่งสร้าง แล้วกด **Deploy** ได้ทันทีโดยไม่ต้องตั้งค่า Build Command เพิ่มเติม
